# 민주당·국회·청와대 기사 텔레그램 채널 봇

15분마다 구글뉴스 검색과 언론사 정치면 RSS를 훑어 민주당·국회·청와대 관련 기사를 채널에 올린다. 같은 제목의 기사가 여러 언론사·피드에서 들어오면 한 번만 올린다.

채널에는 이렇게 올라간다.

```
[민주당] [국회] 김민석 “조희대 사퇴해야”   ← 제목에 기사 링크
중앙일보 · 11.22 21:03
```

## 설치 (처음 한 번, 20분 정도)

### 1. 텔레그램 봇 만들기
1. 텔레그램에서 `@BotFather` 검색 → `/newbot`
2. 봇 이름과 아이디(끝이 `bot`)를 정하면 토큰(`123456:ABC-...`)을 준다. 이 토큰은 남에게 보여주지 않는다.

### 2. 채널 만들고 봇을 관리자로 넣기
1. 새 채널 만들기 (공개·비공개 둘 다 됨)
2. 채널 설정 → 관리자 → 관리자 추가 → 방금 만든 봇 검색 → ‘메시지 게시’ 권한 켜기

### 3. 채널 ID 확인
- 공개 채널: `@채널아이디` 그대로 쓰면 된다.
- 비공개 채널: 채널에 아무 글이나 하나 올린 뒤 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates` 를 열면 `"chat":{"id":-100…` 숫자가 보인다. `-100`으로 시작하는 그 숫자가 ID다.

### 4. GitHub 저장소에 올리기
1. github.com에서 새 저장소 만들기. **Public 권장**(아래 ‘비용’ 참고). 토큰은 저장소가 아니라 Secrets에 들어가니 공개해도 노출되지 않는다.
2. 이 폴더 안의 파일을 모두 올린다. `.github/workflows/news-bot.yml` 경로가 그대로 살아 있어야 자동 실행된다. 웹에서 올릴 땐 폴더째 끌어다 놓으면 된다.
3. 저장소 Settings → Secrets and variables → Actions → New repository secret 두 개 추가
   - `TELEGRAM_BOT_TOKEN` : 1번에서 받은 토큰
   - `TELEGRAM_CHAT_ID` : 3번의 채널 ID

### 5. 켜기
1. 저장소 Actions 탭 → 워크플로 사용 허용
2. `politics-news-bot` → Run workflow 로 한 번 수동 실행
   - 첫 실행은 지금 있는 기사를 ‘본 것’으로만 기록하고 보내지 않는다(채널 도배 방지).
3. 이후 15분마다 새 기사만 올라온다. 바로 확인하고 싶으면 Run workflow를 한 번 더 누르면 된다.

## 고치고 싶을 때 (`config.py`)
- **키워드**: `CATEGORIES`에 단어를 넣고 빼면 된다. 인물이 바뀌면(대표·비서실장 등) 여기서 갈아 끼운다.
- **제외어**: `EXCLUDE`. [포토]·[부고] 등은 이미 빠져 있다.
- **피드 추가**: `FEEDS`에 `{"name": "언론사", "url": "RSS 주소"}` 한 줄. 구글뉴스 검색어를 늘리려면 `_gnews("검색어")` 줄을 복사한다.
- **주기**: `.github/workflows/news-bot.yml`의 `*/15`를 `*/10`, `*/30` 등으로.

## 확인할 것
- 언론사 RSS 주소는 사이트 개편 때 바뀌곤 한다. Actions 실행 기록에 `피드 실패 · 언론사명`이 계속 뜨면 그 주소를 고치거나 지우면 된다. 실패한 피드가 있어도 나머지는 정상으로 돌아간다.
- 중앙일보 정치면 RSS는 주소가 확인되지 않아 넣지 않았다. 구글뉴스 검색에 중앙일보 기사도 잡힌다. 사내 RSS 주소를 알면 `FEEDS`에 추가하면 된다.
- 구글뉴스 링크는 구글을 한 번 거쳐 원문으로 넘어간다.
- GitHub 예약 실행은 붐비는 시간에 5~10분 늦어질 수 있다. 속보 알림용이라기보다 흐름 모니터링용이다.

## 비용
- Public 저장소: Actions 무료, 제한 없음.
- Private 저장소: 무료 한도가 월 2000분인데 15분 주기면 월 약 2900분이 든다. Private로 쓰려면 주기를 `*/30`으로 늘려야 한다.

## 내 컴퓨터에서 시험해 보기 (선택)
```bash
pip install -r requirements.txt
python bot.py --dry-run     # 발송 없이 지금 걸리는 기사 목록만 출력
```
